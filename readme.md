# California Housing Regression Project

This project performs supervised regression using the California Housing Dataset. The goal is to predict median house prices based on features such as location, income, and house age.

## Model Used
- Gradient Boosting Regressor

## Evaluation Metrics
- MAE, RMSE, R² Score

## Results
- R² Score: ~0.82
- RMSE: ~0.48
